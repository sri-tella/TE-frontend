# Tech Stack Documentation

## New Tech Stack Overview
1. **React** - A JavaScript library for building user interfaces.
2. **Redux** - A predictable state container for JavaScript apps.
3. **TypeScript** - A superset of JavaScript that compiles to plain JavaScript.
4. **Tailwind CSS** - A utility-first CSS framework for creating custom designs.

## Setup Instructions
1. **Clone the repository:**  
   ```bash
   git clone https://github.com/sri-tella/TE-frontend.git
   cd TE-frontend
   ```  
2. **Install dependencies:**  
   ```bash
   npm install
   ```  
3. **Start the development server:**  
   ```bash
   npm start
   ```  
4. Navigate to `http://localhost:3000` in your web browser.

## Using Each Library
- **React:**  
  - Create components in the `src/components` directory.  
  - Use `props` and `state` to manage data within components.  

- **Redux:**  
  - Create actions and reducers in the `src/redux` directory.  
  - Use `useSelector` to access state and `useDispatch` to update state in your components.

- **TypeScript:**  
  - Make sure files are saved with `.tsx` extension for React components.
  - Define types and interfaces to enhance type safety.

- **Tailwind CSS:**  
  - Use Tailwind's utility classes directly in your JSX to style components.

## Conclusion
This documentation serves as a guide to understand and set up the tech stack used in this project. For further information, refer to the official documentation of each library.
